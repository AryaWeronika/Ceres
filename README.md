# PL
Cześć! <br>
Znajdziesz tu system do FoundryVTT do polskiego systemu [Ceres RPG](https://hengal.pl/ceres-1), wydany przez wydawnictwo Hengal. <br>
Ceres to gra narracyjna z uniwersum Kalibana (sci-fi), w której gracze wcielają się w kosmicznych kowbojów.<br>
System obsługuje język polski, w przyszłości, może i angielski.
<br>System zawiera:
<br>• Kartę postaci
<br>• System rzutów kośćmi z karty postaci i weryfikuje wyniki rzutów według zasad podręcznika
<br>• Arkusz narratora (MG)<br>

# ENG
Hello!
I am pleased to publish a full-fledged FoundryVTT system for the [Ceres RPG](https://hengal.pl/ceres-1) published by Hengal.<br>
Ceres is a narrative-driven game set in the Kaliban universe (sci-fi), in which players take on the roles of space cowboys. <br>
The system currently supports Polish, with the possibility of English language support in the future.
<br>The system includes:
<br>• A character sheet
<br>• A dice-rolling mechanic integrated into the character sheet, which verifies roll results according to the rules in the core rulebook
<br>• A storyteller (GM) sheet<br>
